# VergiRehber - Vergi Dairesi Müdür Yardımcılığı Sınavı Hazırlık Platformu

Gelir İdaresi Başkanlığı (GİB) Görevde Yükselme / Vergi Dairesi Müdür Yardımcılığı sınavlarına hazırlanan adaylar için tasarlanmış, sade, göz yormayan ve odaklı bir dijital çalışma platformu.

---

## 🌟 Öne Çıkan Özellikler

- **Mevzuat Odaklı Soru Bankası:**
  - VUK (213 Sayılı Vergi Usul Kanunu)
  - GVK (193 Sayılı Gelir Vergisi Kanunu)
  - KVK (5520 Sayılı Kurumlar Vergisi Kanunu)
  - KDV (3065 Sayılı Katma Değer Vergisi Kanunu)
  - AATUHK (6183 Sayılı Amme Alacaklarının Tahsili)
  - 657 Sayılı Devlet Memurları Kanunu
  - 5018 Sayılı Kamu Malî Yönetimi ve Kontrol Kanunu
  - GİB Teşkilat & Vergi Daireleri Kuruluş ve Görev Yönetmeliği
- **Gerekçeli Mevzuat Çözümleri:** Her soru için kanun maddesi referanslı detaylı çözüm açıklamaları.
- **Hap Bilgiler (Flashcards):** Sınavlarda en çok karıştırılan süreler ve hadler için dokunarak çevrilen bilgi kartları.
- **Akıllı Yanlışlar Havuzu:** Yanlış yapılan sorular otomatik toplanır; tek tıkla tekrar çözülerek eksikler giderilir.
- **Süreli Deneme Sınavı:** 20 dakikalık gerçek sınav simülasyonu ve detaylı karne analizi.
- **Göz Dostu Arayüz:** Sade, minimalist tasarım; gece ve gündüz modu desteği.
- **Çevrimdışı & Yerel Hafıza:** İlerleme ve çözülen sorular tarayıcıda güvenle saklanır.

---

## 🚀 Kurulum ve Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için:

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Üretim (Production) derlemesi alın
npm run build
```
